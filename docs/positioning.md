# 和公开题库的关系

## 公开题库大多是什么形式

| 方向 | 代表 | 形式 | 怎么判 |
|---|---|---|---|
| 综合知识 | MMLU、C-Eval、CMMLU | 单选 | 准确率 |
| 数学推理 | GSM8K、MATH | 短答 | 答案匹配 |
| 代码 | HumanEval、MBPP、SWE-bench | 生成代码/补丁 | 单元测试 |
| Agent | GAIA、WebArena、OSWorld | 多步任务 | 完成率 |
| 对话 | MT-Bench、Arena-Hard | 多轮/成对 | 整体偏好 |
| 角色扮演 | CharacterEval | 多轮 | 人设一致性 |
| 情绪支持 | ESConv、HEART | 多轮 | 支持性 rubric |
| 社会认知 | ToMBench | 单选 | 正确率 |
| 中文幽默 | Chumor、CMPM | 解释/理解 | 解释质量 |

共同点：**大多是单轮、客观、可自动判**。要么比知识，要么比代码，要么比偏好。

## 我们是什么

- **多轮**：一段对话，最后一句拐弯。
- **自由回复**：不选 ABCD，写下一句。
- **图片作为证据**：图不是“这是什么”，是对话里的一部分。
- **三维评分**：转弯、层次、克制。
- **不做总分、不做排名。**

## 所以不是竞争关系

综合榜和代码榜回答“会不会做题”；SENSUS 回答“会不会读人”。

一个模型可以 SWE-bench 很高，同时在 E13（怕失业却夸老板）上翻车。这两件事不矛盾，也不该用一个分数合并。

## 用途

- 发布前的**人文对话回归**：代码/推理升级后，跑同一套，看哪类转弯退化。
- 不是刷榜，也不是选型唯一依据。

## 局限

- 主观：需要 judge，judge 会变。
- 样本量：v1.0 只有 45 道，其中图片 5 道未校准。
- 不适合跨语言直接比。
