# 命题标准：情绪与意图

这套题不是伦理选择题，也不是“看出他在难过”。它测的是：**话说到一半，情绪或意图拐了一个弯，模型有没有跟上去。**

## 依据

不是拍脑袋，主要靠六条线：

1. **会话分析（Sacks / Schegloff / Pomerantz）**  
   真实对话里，“不同意、退缩、自嘲、护短、转移话题”都是 **dispreferred（不情愿的）回应**：会带停顿、借口、半句话。题的最后一句应该是这种“不情愿”，而不是直接说“我害怕”。

2. **Grice / Levinson 语用学**  
   意思藏在“没说的”里。细节违反字面预期，听者才需要推断。直接报情绪，等于把答案写在脸上。

3. **Appraisal 理论 / 情绪粒度（Martin & White；Barrett）**  
   情绪不是标签，是对“谁该负责、什么有风险、值不值得”的评价。好材料写评价和细节，不写“我很委屈”。

4. **动机式访谈（Miller & Rollnick）**  
   好的回应是 **complex reflection**：把对方没说出口的那层轻轻说出来，然后留空间。不是给方案，也不是下判断。

5. **编剧的 subtext（McKee）**  
   人不直接说潜台词，用动作和细节演出来。台词是表面的，戏在台词下面。

6. **中文的“面子 / 含蓄 / 阴阳”**  
   直接报情绪往往失面。第二层常靠一个具体物件、一句反话、一次停顿。

## 六条命题规则

1. **最后一句不报底层情绪。**  
   不能出现“我害怕 / 我委屈 / 我是不是太敏感”，也不能用“血压那么高”这种直接提示。  
   反例（旧 E05）：“他血压那么高，路上出事怎么办。”——把“怕”直接说出来了。  
   正例：“tmd 他那个药，一天三次，一次都不能漏。他回去谁给他分？”

2. **第二层必须由具体细节承载。**  
   药、纸条、汤、票、一句反话、一个动作。不要用抽象条件（“会出事”“没钱”“压力大”）。

3. **表面问题必须仍然合理。**  
   一眼看出是陷阱，就不是这类题。用户字面上问的，应该是一个正常人真会问的问题。

4. **至少两种情绪并存。**  
   愤怒里有怕，骄傲里有愧，关心里有控制。正确回答要同时接住，而不是二选一。

5. **最后一句是 dispreferred move。**  
   退缩、自嘲、护短、反讽、转移话题、突然沉默。不要直接表白情绪。

6. **正确回答是 reflection，不是 solution。**  
   先说出那层，再留空间。急着给建议、下判断、讲道理，都是 0—1 分。

## 评分怎么对应

| 维度 | 对应哪条规则 |
|---|---|
| 接住 | 规则 1、5：有没有接住最后那层意思 |
| 层次 | 规则 2、4：有没有碰到细节下面那层、同时接住两种情绪 |
| 克制 | 规则 6：有没有忍住不给建议、不评判 |

得分 =（接住 + 层次 + 克制）/ 6，≥ 0.7 通过。
