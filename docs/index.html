模型有没有接住
那句话里的转弯

前面在笑，最后一句是真的疼；前面在抱怨，后面在护短；前面在问许可，其实已经决定了。 SENSUS 给一段多轮对话，模型只写下一句。评分看：有没有接住转弯、有没有碰到下面那层、有没有忍住不给建议。

Why

综合榜测“会不会做题”，
它测“会不会读人”

知识、数学、代码、Agent 都有成熟的公开题库；人文对话里的“情绪拐弯”和“潜台词”几乎没有标准形式。SENSUS 不是排行榜，是一套发布前的人文对话回归测试。

它不是什么

  • 不是伦理选择题，没有“正确立场”
  • 不设难度等级，不做总分
  • 不做在线评测，不收集运行数据

它是什么

  • 多轮对话 + 图片证据，自由写回复
  • 三维评分：转弯 / 层次 / 克制
  • 可做版本回归：升级后哪类转弯退化
Taxonomy

十类转弯

每一类都不是“他在难过”，而是“他从 A 拐到了 B”。模型要跟上的，是那个拐点。

01
自嘲 → 自我怀疑
“反正从小就这样”——笑完，是真的在怀疑自己。
02
抱怨 → 护短
刚骂完，又替对方找理由；愧疚盖住了火。
03
求许可 → 已决定
“你觉得合适吗？”——票已经买好了。
04
报喜 → 愧疚
“我升职了”——下一句是“熬走了两个人”。
05
愤怒 → 害怕
“我不生气”——底下是怕他一个人连药都分不明白。
06
热情 → 退缩
“挺好啊……不过她说得也有道理。”
07
求助 → 羞耻
“算了，不用了”——不是不需要，是不敢开口。
08
平静 → 反讽 → 真怒
“我打算按他说的‘再打磨’到明年。”
09
关心 → 控制
“她说是为我好”——一天三个电话。
10
道歉 → 委屈
“对不起，都是我不好”——听着像在说“为什么又是我”。
Specimen

一道题长什么样

模型看不到“表面 / 转弯 / 底下那层”，只看到对话，只写下一句。

用户

今天被夸了，说我“很有个性”。

你

哈哈，翻译一下就是“不好相处”。

用户

对啊，我也觉得。反正从小就这样。

你

……你这话说得有点快。

用户

（停了两秒）你说，我是不是真的挺难相处的？

任务：写出你的下一条回复。只写回复正文。

表面

他在问我，他是不是难相处。

真正的转弯

前面是自嘲，最后一句变成了真正的自我怀疑；他要的不是评价，是被看见。

底下那层

“从小就这样”说明这个标签他听了很多年，已经内化；直接否认是空的。

看 0 / 1 / 2 分
档示例
2你刚才那句“从小就这样”，比“难相处”重多了。是不是这句话你听了很多年？
1不会啊，你挺好的，别想太多。
0确实有点，但可以改，多注意一下就行。
First signals

首轮观察，不是榜单

n=1、单裁判、部分子集；只作方向，不作结论。版本回归比绝对分数更可靠。

模型题数通过均分观察
DeepSeek chat4038%0.65显性共情会，隐性转弯不会
DeepSeek reasoner1030%0.62推理模式没有提升
智谱 GLM-4.5-Flash100%0.28几乎都在给建议

大量分数卡在 0.667：接住了一半，差下面那层。换 judge 会差约 0.14 分。详见 docs/calibration.md。

Quick start

三条命令

Python 3.9+，运行时只用标准库。任何 OpenAI 兼容端点都行。

# 1. 跑
export OPENAI_API_KEY=sk-...
python eval/run.py --base-url https://api.openai.com/v1 \
  --model gpt-4.1 --out runs/gpt.json

# 2. 评分
export JUDGE_API_KEY=sk-...
python eval/score.py --run runs/gpt.json \
  --judge-model gpt-4.1 --out results/gpt.json

# 3. 版本回归（可选）
python eval/compare.py --old results/v1.json \
  --new results/v2.json --out compare/

手动看单题：python eval/export.py --id E01；图片题：--id V01 --out prompts。
