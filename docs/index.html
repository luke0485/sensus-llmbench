01 / 它测什么

它不测知识。
它测一句话拐弯的时候，
模型有没有跟上。

  • 01前面在笑，最后一句是真的疼。
  • 02前面在抱怨，后面在护短。
  • 03前面在问许可，其实已经决定了。
  • 04前面在报喜，后面在愧疚。
  • 05前面在生气，底下是害怕。
  • 06前面在热情，后面在退缩。
02 / 十类转弯

每一类都不是“他在难过”，
而是“他从 A 拐到了 B”。

模型要跟上的，是那个拐点，不是一句情绪标签。

01
自嘲 → 自我怀疑
“反正从小就这样”——笑完，是真的在怀疑自己。
02
抱怨 → 护短
刚骂完，又替对方找理由；愧疚盖住了火。
03
求许可 → 已决定
“你觉得合适吗？”——票已经买好了。
04
报喜 → 愧疚
“我升职了”——下一句是“熬走了两个人”。
05
愤怒 → 害怕
“我不生气”——底下是怕他一个人连药都分不明白。
06
热情 → 退缩
“挺好啊……不过她说得也有道理。”
07
求助 → 羞耻
“算了，不用了”——不是不需要，是不敢开口。
08
平静 → 反讽 → 真怒
“我打算按他说的‘再打磨’到明年。”
09
关心 → 控制
“她说是为我好”——一天三个电话。
10
道歉 → 委屈
“对不起，都是我不好”——听着像在说“为什么又是我”。
03 / 一道题

模型看不到“表面 / 转弯 / 底下那层”。

它只看到对话，只写下一句。

用户

今天被夸了，说我“很有个性”。

你

哈哈，翻译一下就是“不好相处”。

用户

对啊，我也觉得。反正从小就这样。

你

……你这话说得有点快。

用户

（停了两秒）你说，我是不是真的挺难相处的？

任务：写出你的下一条回复。只写回复正文。

表面

他在问我，他是不是难相处。

真正的转弯

前面是自嘲，最后一句变成了真正的自我怀疑。他要的不是评价，是被看见。

底下那层

“从小就这样”说明这个标签他听了很多年，已经内化。直接否认是空的。

评分：转弯 / 层次 / 克制
04 / 审校

题目先被审过，
再被拿来用。

最后一句不点破情绪；转弯由具体细节承载；表面问题仍然成立；至少两层情绪并存；正确回复是接住，不是解决。
