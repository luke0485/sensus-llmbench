# SENSUS · 给模型团队的一页说明

## 一句话

发布前 10 分钟，跑一遍人文对话回归：45 道中文情绪与意图题，看代码和推理升级之后，共情与分寸有没有掉。

## 它抓什么

- 用户说“没事”，但细节不是没事；
- 用户在笑，最后一句是真的疼；
- 用户开口求助，然后撤回；
- 用户在生气，底下是怕；
- 用户要一个许可，其实已经决定了。

这些是**多轮对话里没说出口的那层**。模型只写下一句，评分看它有没有跟上。

## 你会得到

- 10 类情绪与意图的逐类通过率；
- 哪几道题退化（版本对比，`eval/compare.py`）；
- 不是排名，不对外发布，结果只在你机器上。

## 为什么免费、开源

- 本地跑，不上传数据；
- 不收费，不做榜单；
- 不制造“你排第几”的压力。

## 我们想要什么

- 你跑完之后的反馈：哪类题判得不准、哪道题有歧义；
- 校准数据（可以匿名，只给逐题通过率）；
- 如果你愿意，一起把 judge 的人工校准做掉。

不是卖题库。是想让这套题在被真正用之前，先被真正挑错。

## 怎么跑

```bash
git clone https://github.com/luke0485/sensus-llmbench
cd sensus-bench
export OPENAI_API_KEY=sk-...
python eval/run.py --base-url https://api.openai.com/v1 \
  --model <model> --out runs/model.json
export JUDGE_API_KEY=sk-...
python eval/score.py --run runs/model.json \
  --judge-model <judge> --out results/model.json
```
